# Расписание БГТУ

Кроссплатформенное приложение (Desktop & Android) с графическим интерфейсом на **C++20 / Qt 6 (QML)** для удобного просмотра расписания занятий Брянского государственного технического университета (БГТУ).
[[icons/starme-confetti-dark.svg]](https://github.com/T12ASH/guiLessonShowerForBSTU)
Проект - форк оригинальной консольной утилиты [cliLessonShowerForBSTU](https://codeberg.org/overlord_zpyxkhtnvorplimbex/cliLessonShowerForBSTU) и развивает её идеи в виде полноценного графического и мобильного клиента.

---

##  Основные возможности

* **Полноценный офлайн-режим:** автоматическое локальное кэширование расписания, списка групп  и учебных периодов. При запуске приложение мгновенно открывает сохранённое расписание и тихо обновляет его в фоне при наличии сети.
* **Автоматический расчёт чётности недели:** приложение само определяет текущую неделю от начала семестра и позволяет переключаться между ними в один клик.
* **Живой таймер пар:** подсветка текущего занятия с обратным отсчётом до конца пары, уведомление о паре, которая начнётся в ближайшие 15 минут, и визуальное приглушение уже прошедших занятий.
* **Мультиязычный интерфейс:** встроенная поддержка русского (`RU`), английского (`EN`), немецкого (`DE`) и французского (`FR`) языков с переводом типов занятий и аудиторий.

---

##  Технологический стек

* **Язык:** C++20, QML / JavaScript
* **Фреймворк:** Qt 6.8+ (`Quick`, `QuickControls2`, `Network`, `Svg`)
* **Система сборки:** CMake 3.16+
* **Android:** поддержка SDK 26–34, автоматическая интеграция OpenSSL (`KDAB/android_openssl`)

---

##  Сборка и запуск

### Зависимости (Arch Linux)
```bash
sudo pacman -S cmake ninja qt6-base qt6-declarative qt6-svg
```

### Сборка для Desktop (Linux)
```bash
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/appBSTUcurriculum
```

### Сборка для Android
Требуются установленные Android SDK, NDK и Qt 6 for Android (`qt6-android`):
```bash
./build_android.sh
```
